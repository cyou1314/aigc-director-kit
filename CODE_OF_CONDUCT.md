# CineThread Code of Conduct

## Our standard

We want CineThread to be a practical, respectful place to improve creative
workflow tooling. Participate in good faith, focus on the work, and treat
other contributors with respect.

## Expected behavior

- Give reproducible, evidence-based feedback.
- Separate designed contracts, dry runs, rendered output, and observed QC.
- Explain the provenance and redistribution rights of any external asset or
  motion data proposed for the project.
- Keep review discussion focused on the code, documentation, and user impact.

## Unacceptable behavior

- Harassment, discrimination, personal attacks, or bad-faith disruption.
- Uploading credentials, cookies, private media, private reference assets, or
  local absolute paths.
- Presenting generated media, a maintainer's alternate account, or unverified
  results as independent community evidence.

## Reporting

For a conduct concern, open a private contact through the repository owner's
GitHub profile rather than posting sensitive details in a public issue.
